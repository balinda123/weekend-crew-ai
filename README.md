# 馋猫局儿（Chanchat Crew）

面向多人旅行的 AI 共创工具：一起收集地点，在地图上生成可编辑行程，出行中记账并生成 AA 结算，再把脱敏后的真实路线发布到公开行程广场。白色田园猫“芝士”负责路线与地点识别，“奶糖”负责账本与结算。

## 当前产品流程

~~~text
微信快捷登录 → 新建私密攻略 → 成员共同添加地点 → 地点满 3 个 → AI 规划可编辑行程
             → 行中记账 → 显式生成 AA 结算 → 提交脱敏发布 → 广场搜索/复用
~~~

全局只有“首页、我的”两个菜单。行程详情内部包含“地图与行程、AA 账本”。

## 核心能力

- 首次进入先完成微信快捷登录；首页提供公开行程广场、关键词搜索和双列瀑布流
- 自定义攻略名称、热门目的地、全国省/市/区三级选择
- 私密与公开攻略统一采用地图 + 抽屉；公开抽屉含地点总览和按天行程列表
- 两种加地点方式：地图 POI 搜索、公开分享链接智能识别；首版不提供地图中心点选点
- 小红书/抖音链接采用受控解析；不可访问时降级到复制文字或截图 OCR
- AI 规划必须至少有 3 个已确认地点，成功后才扣积分
- 行程按攻略起止日期生成 Day 1…N；AI 与手动节点都必须归属具体日期，允许空白日
- AA 账本采用“持续记账 → 生成结算”两阶段，账单变化后旧结果失效
- 首页与我的统一浅色流式卡片；个人资料、积分和 AI 次数合并为紧凑页头，下方展示我创建的、我加入的和收藏
- 攻略创建后默认私密，仅成员可见；审核通过的脱敏快照才进入公开广场
- 微信 code 建立身份，头像和昵称由用户确认；首次确认完成后进入产品
- 设置页提供日光橘、珊瑚汽水、青柚森林、莓果晴空四套原型渐变候选

## 积分与成本保护

- 新用户基础积分：100
- AI 行程成功生成：-20
- 分享链接成功解析：-5
- 公开攻略审核通过：+30，每月最多奖励 3 次
- AI 行程：每月最多 5 次、每日最多 3 次
- 失败、取消或超时不扣分；服务端使用预占、确认、释放和幂等流水

首版积分不可购买、转赠或提现。

## AI 与数据原则

- AI 不充当通用聊天框，只参与地点结构化、行程编排和解释。
- 搜索、截图或链接产生的地点必须经过地图 POI 校验和用户确认。
- 不绕过第三方平台登录、验证码、反爬或访问权限，不镜像受限正文。
- 行程排序由确定性约束与 LLM 编排结合；AA 金额与结算不交给 LLM。
- AI 输出必须通过结构化校验，调用过程记录成本、缓存和模型版本。
- 公开攻略详情只读取脱敏快照；AA 账单、分摊和转账关系永不进入公开响应。
- 小程序首次进入必须完成微信身份登录并确认头像昵称；登录成功后才能浏览首页和公开广场。

## 技术规划

| 层 | 方案 |
|---|---|
| 前端 | Taro + React + TypeScript + NutUI React Taro |
| 后端 | Python + FastAPI |
| 数据 | PostgreSQL + PostGIS |
| 缓存与异步任务 | Redis + Worker |
| 地图 | MapProvider 适配层，首选高德 |
| AI | OCR、地点实体提取、POI 匹配、约束引擎、LLM 结构化输出 |
| 契约 | OpenAPI，生成前端 TypeScript 类型 |
